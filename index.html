AI agent memory

7 primitives: working, long-term, episodic, keyword, graph, bi-temporal, procedural. Lineage as a first-class primitive. Built to beat Mem0, Zep, Letta.

RAG as a query

Hybrid dense+sparse retrieval fused with Reciprocal Rank Fusion, planned by the same cost-based optimizer that plans joins. Not a bolted pipeline.

In-engine man-in-the-middle flags STALE_HIT / PHANTOM on every cache read. Provable per-key staleness with the exact version delta. No guessing.

AI Memory

Seven memory primitives. One substrate.

Every category leader's core memory type, on one engine, in one process. Provenance / lineage as a first-class primitive — the non-malleable-authority hardening 2026 agent-memory research demands.

WM

Working Memory

Hot per-agent context, TTL-cleared. Redis speed on the durable engine.

LTM

Long-Term Memory

Durable semantic store in HNSW. Lineage-attached: source, salience, derivation chain.

EP

Episodic

Append-only event log. Queryable by agent + kind. The event timeline.

KW

Keyword Index

BM25 inverted index. Exact-term recall that pure-vector memory misses.

GRAPH

Graph Memory

Typed edges, forward + reverse index. MEM.LINK / NEIGH / TRAV for BFS traversal.

BITEMP

Bi-temporal Facts

valid_from / valid_to on LTM. RECALL.AS_OF: "what did we know at time T?"

PROC

Procedural Memory

Per-agent workflows and rules. Stored by name, retrieved on demand.

# remember something (source + salience + embedding)
redis-cli -p 6380 MEM.REMEMBER "user prefers Rust for speed" user 0.9 1.0 0.2 0.0

# blended semantic + keyword + salience recall
redis-cli -p 6380 MEM.RECALL 5 "rust speed preference" 1.0 0.2 0.0

# graph edges
redis-cli -p 6380 MEM.LINK alice works_at acme 1.0
redis-cli -p 6380 MEM.TRAV alice 3

# bi-temporal — "what did we know at time T?"
redis-cli -p 6380 MEM.REMEMBER.T "CEO of Acme" user 0.8 3000 0 1.0 0.2 0.0
redis-cli -p 6380 MEM.RECALL.AS_OF 5 "CEO" 5000 1.0 0.2 0.0

# working memory (TTL-cleared per-agent context)
redis-cli -p 6380 MEM.WM_SET alice session_ctx "midnight launch plan" 60000
redis-cli -p 6380 MEM.WM_GET alice session_ctx
redis-cli -p 6380 MEM.WM_DELETE alice session_ctx

# episodic — append-only event log, queryable by agent + kind
redis-cli -p 6380 MEM.EPISODE alice click '{"page":"/pricing"}'
redis-cli -p 6380 MEM.EPISODES alice 50
redis-cli -p 6380 MEM.EPISODE_FORGET alice <seq>

Quick Start

Running in 30 seconds

# build — pure stdlib Rust, zero external crates
cargo build --release

# launch on the RESP wire
DBSTRIKE_WAL=./dbstrike.wal ./target/release/dbstrike 127.0.0.1:6380

# talk to it with any Redis client
redis-cli -p 6380 PING                 # -> PONG
redis-cli -p 6380 SET user:1 ada
redis-cli -p 6380 VADD 1 1.0 0.0 0.0
redis-cli -p 6380 VSEARCH 5 1.0 0.0 0.0
redis-cli -p 6380 SUBSCRIBE trades &
redis-cli -p 6380 PUBLISH trades "hello"
redis-cli -p 6380 CHECKPOINT           # snapshot + WAL truncate

# native Rust bench — 18 sections, YCSB, chaos
cargo run --release -p bench

# Python integration + fuzz + crash recovery
python3 tests/test_dbstrike.py
