What you get

The combined-Apple approach: take each category leader's advantage and close the database gaps with novel in-house techniques — one license, one consistency model.

⚡

Unified substrate

MVCC + WAL engine. Tables, KV, vectors, time-series and the CDC log are all key conventions over one store — zero dual-write drift.

🧠

AI agent memory

Working / long-term / episodic / keyword, with provenance lineage as a first-class primitive Mem0·Zep·Letta don't ship.

🔍

RAG as a query

Hybrid dense+sparse retrieval fused with Reciprocal Rank Fusion, planned by the same cost-based optimizer that plans joins.

🐞

MITM cache debugger

An in-engine man-in-the-middle that flags STALE_HIT / PHANTOM on every cache read — provable staleness, instantly.

🏎️

Fuel-metered reducers

Logic runs in-DB like SpacetimeDB, but bulkheaded by shard, fuel-metered, and circuit-breaker protected. No global stall.

🔄

Reactive sync + CDC

Pub/sub and a durable change-log fed by the commit hook. Decoupled from the write path for availability.

AI agent memory, built to win

Four memory structures on the same substrate. Blended semantic + keyword recall, salience-weighted, with non-malleable lineage so poisoning is detectable.

🔥

Working (STM)

Hot per-agent context, TTL-cleared, Redis speed — but the same rows the durable engine sees.

🗄️

Long-term (LTM)

Durable semantic store, pushed into the shared HNSW for one-hop recall. Lineage-attached.

📜

Episodic

Append-only event log of everything that happened, queryable by agent + kind.

🔤

Keyword index

BM25-ish inverted index over LTM text — exact-term recall that pure-vector memory misses.

Get running in 30 seconds

# build (pure stdlib Rust — no external crates)
cargo build --release

# serve the RESP wire on 127.0.0.1:6380
DBSTRIKE_WAL=./dbstrike.wal ./target/release/dbstrike 127.0.0.1:6380

# talk to it with any Redis client
redis-cli -p 6380 PING                 # PONG
redis-cli -p 6380 VADD 1 1.0 0.0 0.0
redis-cli -p 6380 VSEARCH 5 1.0 0.0 0.0

# full production test + benchmark suite
python3 tests/test_dbstrike.py
